# Tendora App Store Screenshot Plan

Updated: August 25, 2026

Use this plan after loading the screenshot demo data.

## Goal

Show Tendora as:

- organized
- useful for real-life maintenance
- easy to understand in one glance

The screenshots should emphasize:

1. assets overview
2. upcoming maintenance
3. reminders and task details
4. calendar planning
5. documents and attachments

## Before Capturing

| Item | Action |
|---|---|
| Demo data | Load the screenshot demo data from Settings |
| Device support | Confirm only `iPhone` and `iPad` are planned for release |
| Language | Capture App Store screenshots in English first |
| Appearance | Use light mode unless dark mode looks clearly better |
| Battery/time | Use a clean simulator status bar if possible |
| Notifications | Avoid active banners or permission popups in screenshots |
| Settings tab | Do not use Settings as a main App Store screenshot unless needed |

## Recommended iPhone Shot List

Use 5 screenshots.

| Order | Screen | What Must Be Visible | Message It Communicates |
|---|---|---|---|
| 1 | Home | Multiple assets and several upcoming tasks | `Everything you own in one place` |
| 2 | Asset Detail | A strong asset like `Volvo XC60` or `Home` with tasks and documents | `Track each asset clearly` |
| 3 | Task Detail | A task with due date, repeat rule, reminder, and attachments | `Never miss maintenance` |
| 4 | Calendar | Several due dates across the month | `See what is coming up` |
| 5 | Documents | Mixed attachments from multiple assets/tasks | `Keep photos and documents together` |

## Recommended iPad Shot List

Use the same 5 screens unless one looks weak on iPad.

| Order | Screen | What Must Be Visible | Notes |
|---|---|---|---|
| 1 | Home | Assets and upcoming tasks visible without feeling sparse | Make sure the layout does not look empty |
| 2 | Asset Detail | A rich asset with tasks, history, and attachments | Prefer `Home` or `Volvo XC60` |
| 3 | Task Detail | Reminder settings, due date, and completion history | Use a task with attachments if possible |
| 4 | Calendar | Multiple visible due dates in the same month | Choose the month with the best spread |
| 5 | Documents | Several attachments with strong filenames/types | Avoid showing awkward truncation if possible |

## Best Data To Use For Each Screen

| Screen | Recommended Demo Content |
|---|---|
| Home | All seeded assets plus upcoming tasks |
| Asset Detail | `Volvo XC60` if you want a clean car example, or `Home` if you want a broader household example |
| Task Detail | `HVAC service`, `Annual service`, or `Engine service` |
| Calendar | Month view with several due dates in late August, September, October, and November 2026 |
| Documents | Mixed files from `Home`, `Volvo XC60`, and `Raptor` |

## Screenshot Quality Rules

| Rule | Why |
|---|---|
| Do not show empty states | Full screens sell the app better |
| Do not show destructive dialogs | They look unfinished |
| Do not show demo-tool controls | They are not part of the product story |
| Do not show the notification permission prompt | It distracts from the app |
| Do not capture while a temporary toast is half-visible | It looks accidental |
| Prefer screens with 1 clear story | Each screenshot should communicate one benefit |

## Screen-By-Screen Capture Notes

## 1. Home

Use this if the first screen needs strongest marketing value.

Checklist:

- At least 4 assets visible
- At least 3 upcoming tasks visible
- No awkward empty gaps
- Clean tab selection

Suggested caption idea:

`Organize every asset in one place`

## 2. Asset Detail

Checklist:

- Asset name is strong and easy to understand
- Tasks section is populated
- Documents section is visible if possible
- Layout looks intentional without too much scrolling cut-off

Suggested caption idea:

`Track maintenance for every asset`

## 3. Task Detail

Checklist:

- Due date visible
- Repeat rule visible
- Reminder visible
- Attachment section or history visible

Suggested caption idea:

`Stay ahead with smart reminders`

## 4. Calendar

Checklist:

- Month has several marked due dates
- Selected day shows useful tasks
- The screen reads clearly at a glance

Suggested caption idea:

`Plan upcoming work at a glance`

## 5. Documents

Checklist:

- Multiple attachment rows visible
- Different document types visible if possible
- File names look realistic and clean

Suggested caption idea:

`Keep manuals, receipts, and photos together`

## Optional Sixth Screenshot

Only add this if one of the main five looks weak.

| Screen | When To Use It |
|---|---|
| Onboarding | If the onboarding looks polished and adds clear value |
| Settings | Only if the settings screen looks polished and supports the story |
| Another Asset Detail | If one asset type tells the product story better on iPad |

1. Load demo data
