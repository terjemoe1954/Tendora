# Tendora App Store Release 1.3

Version: `1.3`
Build: `6`

## What's New

Backup and restore is now available in Settings. You can export your Tendora data to a `.tendorabackup` file and restore it later when needed.

This update also improves backup file handling so Tendora backup files can be selected correctly from Files during restore.

## Longer Release Notes

- Added manual backup export from Settings.
- Added restore from `.tendorabackup` files.
- Restore shows a confirmation step before replacing local Tendora data.
- Backups include assets, tasks, completion history, reminders, and attachments when attachment data is available.
- Tendora backup files are now registered with iOS so they can be selected from Files.
- Updated the user manual with backup and restore instructions.

## App Review Notes

Tendora 1.3 adds user-controlled backup and restore. Backup files are exported and imported through the standard iOS document picker. Restore requires explicit confirmation before local Tendora data is replaced.

No new account system or server-side backup service is included in this version.
